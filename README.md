# Office Calendar 🗓️

A modern, light-weight office calendar and scheduling application designed to streamline event planning, room bookings, and team availability management.

---

## 🌟 Features

* **Event Management:** Create, edit, and manage office meetings, events, and company holidays.
* **Room & Resource Booking:** Reserve shared office spaces, meeting rooms, and equipment seamlessly.
* **Interactive Views:** Switch easily between Month, Week, Day, and Agenda views.
* **Filter & Search:** Quick lookup for events by team, category, or location.
* **iCal / .ics Export:** Sync events easily with third-party calendars like Google Calendar, Apple Calendar, or Outlook.
* **Responsive UI:** Fully optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Built With

* **Frontend:** React / Modern JavaScript
* **Styling:** CSS3 / Tailwind CSS
* **Build Tool:** Vite / Webpack

## 🚀 Getting Started

Follow these instructions to get a local copy up and running for development and testing purposes.

### Prerequisites

* [Node.js](https://nodejs.org/) (v16.0 or higher)
* `npm` or `yarn` / `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NERONSW/office-calendar.git
   cd office-calendar
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` (or the port specified in your terminal) to view the application.

---

## 📦 Building for Production

To create a production build:

```bash
npm run build
```

The output will be generated in the `dist/` or `build/` directory, ready to be deployed to your hosting provider.
